# Component specifications

This spec defines the presentation contract for the shared existing HTML controls. New primitives are not substituted for product controls, so their current click, keyboard, form, loading, and data behavior remains in place. The common CSS token layer supplies the shared appearance; the concrete component files below are the migration/inspection entry points.

| Primitive | Anatomy and dimensions | Required states | Motion | Accessibility contract / current entry points |
|---|---|---|---|---|
| Button | Label or icon + optional spinner; 28 px small / 32 px default desktop, 40 px mobile; 6 px radius | Default, hover, focus-visible, pressed, disabled, loading | 80 ms scale to .98 on press; 120 ms color/focus | Keep native `button`, type, disabled and existing `onClick`; loading keeps label and sets `aria-busy`. Settings submit follows this contract. |
| IconButton | Single Lucide icon; 24 px visual, 40 px mobile hit area; 6 px radius | Same six button states | 80 ms press, 120 ms icon color | Require `aria-label` or title/name; examples in `Header.tsx`, `SettingsModal.tsx`. |
| Input | Label + field; 32 px desktop / 40 px mobile; 16 px mobile font; 6 px radius | Default, hover, focus-visible, invalid, disabled, loading where applicable | Focus border/ring 120 ms | Label must be associated or an accessible name supplied; settings API key label is associated in `SettingsModal.tsx`. |
| Select | Label + native/custom trigger + option list; 32/40 px | Default, hover, focus-visible, selected, disabled, loading | 120 ms color; options 120 ms fade/4 px | Keep native select or existing roles, selected value, keyboard and Escape behavior. |
| Tabs | Label row with 2 px underline; 40 px minimum hit target | Default, hover, selected, focus-visible, disabled, loading if data-backed | Shared underline `layoutId`, 200 ms | Use tab semantics only for actual in-page tab panels; keep `aria-selected` and keyboard selection together. Navigation remains `nav` with `aria-current`. |
| SegmentedControl | Joined choices, 32 px desktop / 40 px mobile; 6 px radius | Default, hover, selected, focus, disabled, loading if data-backed | Shared indicator `layoutId`, 200 ms | Preserve single-choice behavior. Chart timeframe controls use `role=group` and retain existing click handlers. |
| Badge / Status pill | Neutral surface, 22 px high, 4 px radius, 12 px type | Neutral, positive, negative, warning, stale | No motion | State always has visible text; positive/negative quote changes retain sign and direction arrow where already shown. |
| Skeleton | Rectangles/lines shaped to final metric, row or card | Loading only | Static, low-contrast; no shimmer under reduced motion | Containing region can expose `aria-busy`; current screens still use some spinners and are recorded in the audit. |
| Tooltip | Text panel, max width 240 px, 12 px type | Hidden, hover, focus, dismissed | 120 ms opacity/4 px; 300 ms hover delay | Do not open from touch unless current behavior does; use `role=tooltip` and described-by linkage. |
| Dropdown | Surface and hairline border; shadow only while elevated | Closed, open, hover, focus, disabled action | 120 ms opacity/4 px | Escape closes where existing behavior supports it; menu button exposes `aria-expanded`; retain trigger focus. Header profile menu is the existing example. |
| Dialog | Surface, 8 px radius, internal scroll, max 90 dvh | Closed, opening, open, focus, error, disabled action | Fade + 0.98 to 1 over 200 ms | `role=dialog`, `aria-modal`, labelled by visible title. Settings keeps its current close/save behavior. |
| Sheet | Surface, mobile bottom / desktop side, 12 px top radius mobile, 90 dvh max | Closed, opening, open, dragging, error, disabled action | 280 ms panel entry; reduced motion opacity 120 ms/no travel | Search has a labelled dialog, initial focus, focus return and 40%/high-velocity drag-to-dismiss. Escape remains supported by its current key handler. |
| Toast | Status message + optional action | Entering, visible, exiting, success, error | 200 ms enter, 120 ms exit; 4 s target | Use status/live-region semantics and preserve current auto-dismiss policy. No shared toast provider exists in this repository. |
| Table | Header, aligned columns, hairline row separators; 32/36 px desktop rows | Default, hover, focus, selected, disabled, loading | No layout animation | Numeric cells use tabular figures/right alignment; mobile keeps every field reachable in an inner horizontal scroll or existing expansion. |
| Accordion / expandable row | Trigger + grid-row content | Collapsed, expanded, hover, focus, disabled, loading | 200 ms grid-template-rows (0fr to 1fr) | Trigger exposes `aria-expanded` and controls panel; preserve existing row behavior. No shared accordion primitive is present. |

The six-state matrix is a specification, not a claim that every individual control has been rendered in a test gallery. Adding a `/design` route would violate the unchanged-route contract; no separate product route was added.
