# Design decisions

## 2026-10-31 — Visual refresh direction

Use a restrained market-terminal visual language: neutral page and panel surfaces, slate text, one blue interaction accent, flat active navigation, and consistent borders. Remove decorative glow, gradient text, exaggerated card hover movement, and oversized promotional copy. Preserve the existing light/dark switch and market features while making data pages denser and easier to scan. On mobile, use five destinations (Markets, Stocks/Assets, Search, Watchlist, More) and route More through the existing navigation drawer.
